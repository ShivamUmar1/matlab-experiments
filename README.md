# MATLAB Experiments & Signals and Systems Project

A collection of MATLAB laboratory experiments and projects covering Signals and Systems, Digital Signal Processing fundamentals, signal generation, system analysis, and audio signal convolution.

---

## 📁 Repository Structure

| File | Description | Topics Covered |
| :--- | :--- | :--- |
| **`exp_1.m`** | Arithmetic Operations & Elementary Waveforms | Arithmetic operations, Continuous sine wave, Discrete-time cosine wave |
| **`exp_2.m`** | Basic Elementary Signals | Unit impulse, Unit step, Unit ramp, and Signum functions |
| **`exp_3.m`** | Standard Waveform Generation | Sine, Cosine, Sinc function, and signal plotting |
| **`exp_4.m`** | System Linearity & Properties | Verifying linearity and properties of discrete-time systems |
| **`exp_5.m`** | Discrete Convolution | Custom implementation of linear convolution (`Conv_user`) |
| **`exp_6.m`** | System Impulse Response | Impulse response analysis of discrete-time LTI systems using `impz` |
| **`exp_7.m`** | Fourier Series Synthesis | Fourier series approximation of periodic square waves using harmonics |
| **`exp_8.m`** | Exponential Signals & Transformations | Real/complex exponential signal generation and plotting |
| **`exp_9.m`** | Z-Transform & Inverse Z-Transform | Symbolic computation of Z-transform and Inverse Z-transform using `ztrans`/`iztrans` |
| **`ss_project.m`** | Signals & Systems Capstone Project | Audio signal processing, custom linear convolution of two audio signals, normalization, time-domain waveform visualization, playback, and export |

---

## 🚀 How to Run

1. Open **MATLAB** (R2018a or newer recommended).
2. Set the current folder in MATLAB to this repository directory:
   ```matlab
   cd('path/to/MATLAB Experiments')
   ```
3. Run any experiment directly from the MATLAB command window or Editor:
   ```matlab
   run('exp_1.m')
   ```
4. For `ss_project.m`, ensure valid audio input paths are configured for reading audio files.
